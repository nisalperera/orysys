# INC-2026-011 Payment failure incident report

**Severity:** P1  
**Date:** 2026-03-12  
**Affected service:** wallet-service  
**Duration:** 27 minutes  
**Failed transactions (approx):** 5350

## Summary
Customers experienced failed payment transactions. Primary symptom: authorisation errors and timeouts on wallet-service.

## Timeline
- T+0: Alert fired on payment success rate dropping below 97%.
- T+8: On-call engineer acknowledged and opened the incident channel.
- T+17: Mitigation applied.
- T+27: Success rate recovered above 99.5%.

## Root cause
Root cause category: Faulty configuration deployment (transaction limit flag).  
A feature-flag change set the per-transaction limit to 0 for retail wallets. The change skipped peer review because it was classed as a non-code change.

## Corrective actions
Config changes now require two approvals and a canary rollout of 5% for 15 minutes.

## Lessons learned
Detection took longer than target (target is 5 minutes). Runbook coverage for this failure mode was incomplete.
